# 轻舟 Launchroom

面向个人创作者的中文部署工作台：平台导航、收藏、最多三个平台比较、本地项目计划、四步清单、HTTPS 网址记录、JSON 备份导入导出、Markdown 发布指南与起步 HTML 下载。

## 打开与发布

原生 HTML、CSS、JavaScript，无构建依赖。推荐通过任意静态服务器打开本目录；直接打开 index.html 也能浏览，但剪贴板与本地保存受浏览器策略影响。

GitHub Pages：从 main 分支根目录发布；`.nojekyll` 禁用 Jekyll。Cloudflare Pages：无需框架与构建命令，输出目录为本目录。

## 功能边界

工作台不会登录云平台、读取账户额度或自动执行远程部署。项目、收藏、清单保存在当前浏览器 localStorage，清单完成度是用户记录。外部网址在新标签打开。请通过导出 JSON 备份跨设备迁移；导入会合并，不替换既有项目。

平台文本是路线说明，非价格保证。每个平台提供官方文档入口。Railway 试用不等于长期免费，Netlify 配额限制与 EdgeOne 域名区域规则需在实际发布时核对。

## 设计来源

以用户提供的 LightVela 设计系统提取文档为视觉参考：白色细竖纹、暖黑文字、深紫行动色、暗橄榄标识、胶囊 CTA、双栏产品布局与轻投影。品牌、文案、图形与交互为本项目创作。参考文档中的登录态数据、聊天内容与会话信息没有复制到本项目。

所有视觉资源均为本地 SVG / CSS；不加载外部字体、分析脚本或付费服务。
